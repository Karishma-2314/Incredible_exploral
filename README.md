# Incredible Explorer 🌍

Incredible Explorer is a tourism website project developed using HTML, CSS, and JavaScript.

This project helps users explore famous tourist places in Telangana and Andhra Pradesh through an interactive and user-friendly interface.

## Features 

- User Login and Sign Up
- LocalStorage authentication
- Dynamic state and district selection
- Tourist place display with images and descriptions
- About project section
- Team members section
- Rating system
- Responsive design
- Attractive travel-themed UI

## Technologies Used 💻

- HTML5
- CSS3
- JavaScript
